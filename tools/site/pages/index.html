What is NovelForge? It is free, open-source novel writing software for Windows. It gives you a binder of chapters and scenes, a corkboard, nine outline frameworks, a timeline, reference sheets for characters and places, a story graph that checks continuity, a procedural fantasy map maker and offline prose diagnostics. Unlike most writing apps it stores your book as ordinary Microsoft Word (.docx) files, one per scene, so nothing is locked in a database and nothing is uploaded anywhere.

Getting started

Four steps, no technical background needed

NovelForge runs on Windows 10 and 11. There is no installer: you unzip a folder and double-click one file.

1

Install Python

Free, from python.org. Version 3.13 or newer; tick “Add python.exe to PATH”.

2

Download NovelForge

Get the latest release’s Source code (zip) from GitHub and unzip it anywhere.

3

Double-click Write.bat

It finds Python and, the first time only, installs the two small libraries NovelForge needs. That needs the internet once.

4

Start writing

Choose File → New Novel, give it a title and a word target, and type. It saves itself.

Questions

Quick answers

Is NovelForge really free?

Yes. It is free and open source under the MIT licence. There is no trial period, no subscription, no locked feature and no account. If it helps you, a donation is welcome but never expected.

Where are my files stored?

In a normal folder on your own computer, Projects\Your Novel\. Every scene is its own Word (.docx) file. A small project.json remembers only ordering, links and word counts, never your prose.

Does it use AI?

No. There is no generative AI in NovelForge and nothing reads your manuscript except the program on your machine. The prose checks are ordinary offline rules that point at problems; they never rewrite your text.

Does it work on Mac or Linux?

Not yet. The engine is plain Python, but the interface has only been built and tested on Windows 10 and 11. If Mac or Linux support would get you using it, please say so on GitHub.
