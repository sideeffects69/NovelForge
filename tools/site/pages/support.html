Other ways to help

  • Tell a writer. The most useful thing you can do is mention NovelForge to someone who is trying to finish a book.
  • Star the project on GitHub; it helps other writers find it.
  • Report what feels wrong. “It felt glitchy when I did this” is a complete bug report. Open an issue.
  • Ask for what you need. If Mac or Linux support, a new outline framework or a new map style would change how you write, say so.
  • Contribute. Code, tests, documentation and name lists are all welcome; see CONTRIBUTING.md.
