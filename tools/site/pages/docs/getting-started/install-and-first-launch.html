Learn how to install NovelForge on Windows 10 or 11, start it for the first time and create your first novel. There is no installer: you install Python once, unzip a folder and double-click one file.

What you need

  • Windows 10 or 11. NovelForge has only been built and tested on Windows. macOS and Linux are not supported.
  • Python 3.13 or newer. It is a free program from python.org that NovelForge runs on.
  • Two small Python libraries, python-docx (it reads and writes the Word files) and Pillow (it draws the map images). Write.bat installs them for you the first time; that is the only time NovelForge needs the internet.

Install Python

Download Python from python.org, choose version 3.13 or newer, and on the first screen of the installer tick Add python.exe to PATH. If you prefer a terminal, this command does the same job:

winget install Python.Python.3.13

If you forget to tick the box, run the Python installer again and choose Modify. Write.bat also looks for Python in its usual per-user folder, so it often works either way.

Download NovelForge

Open the latest release on GitHub, scroll to Assets and download Source code (zip). Unzip it anywhere you like: the Desktop or Documents is fine. The folder is the whole program; there is nothing to install into Windows.

Start it with Write.bat

Double-click Write.bat in that folder. In order, it does the following:

  1. Looks for Python (first in the usual per-user install folder, then on your PATH). If there is none, it explains how to get it and waits, instead of closing.
  2. Checks for the two libraries. If they are missing it installs them with pip, which needs the internet once. If that fails it tells you to check your connection and try again.
  3. Starts NovelForge through pythonw.exe, so there is no black console window behind the program.

Windows may show a warning for a file downloaded from the internet. Write.bat is a short plain-text script, so you can open it in Notepad and read it before you run it. The download page lists the common problems and their fixes.

The first screen

On a fresh install there is no novel yet, so NovelForge shows a welcome screen with two buttons, Start a new novel and Open an existing novel, and a short reminder that Ctrl+Shift+P opens the command palette, where you can find any command by typing its name. Once you have written something, NovelForge reopens your last novel when it starts, and the welcome screen only comes back if there is nothing to open.

Create your first novel

Choose File → New Novel (Ctrl+Shift+N) or press Start a new novel. The form asks for:

  • Title, plus an optional subtitle, your author name, an optional series name and a genre.
  • Structure, one of the nine outline frameworks. Three-Act is the default, and you can switch later without losing anything you have written under another one.
  • Target word count and daily word target, filled in from your preferences (90,000 and 1,000 words at first), and an optional deadline in the form 2027-03-01.
  • Extra template packs: Fantasy / Sci-Fi (ticked by default; the full world bible is always created), Mystery / Crime (adds a Clue Tracker) and Romance (adds a Relationship Arc Tracker).
  • Location, which is the Projects folder next to Write.bat unless you choose another. NovelForge creates a folder there named after your title.

Press OK and NovelForge builds the whole project: the numbered folders, a set of starter Word documents (a premise sheet, world-bible sheets, a query letter, a synopsis and more), an outline for the framework you chose, and a first chapter called Chapter One with a scene called Opening Scene. Choose that scene in the binder on the left and start typing. Your text saves itself after a pause.

Where things live

Your novels are in the Projects folder next to Write.bat, one sub-folder per book, and your preferences are in novelforge-settings.json beside it. File → Open Project Folder shows the current novel in Explorer. For a desktop shortcut with the NovelForge icon, double-click Make Desktop Shortcut.bat once.

To upgrade, unzip the new release into a new folder and copy your Projects folder and novelforge-settings.json across before you start it. Deleting the old folder deletes the novels inside it, so copy them first.
