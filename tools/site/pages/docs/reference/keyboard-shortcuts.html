Every keyboard shortcut in NovelForge's main window, by menu. This page is generated from the program's own source code each time the website is built, so it lists exactly the keys the menus show, and it cannot fall behind the program.

You do not have to remember any of them. Press Ctrl+Shift+P to open the command palette, type a few letters of what you want (story graph, backup, theme) and press Enter. It searches every command in every menu.

How undo and redo behave

Undo has two jobs, and which one you get depends on where the cursor is. With the cursor inside the writing area, Ctrl+Z undoes your typing. Anywhere else, it undoes the last change to the project: a rename, a move, a delete, an edit in the inspector. Ctrl+Alt+Z undoes the last project change even while the cursor is in the text, and Ctrl+Alt+Y redoes it. Choosing Edit → Undo from the menu always undoes the project, and its label names what it would take back.

In the binder

  • Right-click a row for the actions that fit it.
  • Double-click a sheet, note or document to open it in Word, a map to open it in the map maker.
  • Type letters to jump to the first row whose name begins with them.
