# Files for the root of sideeffects69.github.io

GitHub Pages serves a *project* site (this one, NovelForge) from
`/NovelForge/`. Search engines and AI crawlers only look for `robots.txt` and
`llms.txt` at the **root of a host**, so on their own the copies inside
`site/` are never found.

The root of `sideeffects69.github.io` is served from a repository named exactly
that. To publish these files:

1. On GitHub, create a **public** repository named `sideeffects69.github.io`.
2. Put the files in this folder at the top of it: `robots.txt`, `llms.txt`
   and `index.html` (not this README).
3. In that repository's Settings > Pages, publish from the `main` branch,
   folder `/ (root)`.
4. Check that https://sideeffects69.github.io/robots.txt and
   https://sideeffects69.github.io/llms.txt open in a browser.

These files are generated by `python tools/build_site.py` and must not be edited
by hand. Nothing in this repository publishes them.
