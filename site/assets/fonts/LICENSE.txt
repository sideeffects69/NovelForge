Fonts used by this website
==========================

Inter (body text) and Literata (headings) are self-hosted so that no page asks
a third party for anything. Both are free fonts under the SIL Open Font
License 1.1, reproduced below as that licence requires.

  inter-latin.woff2     Inter, variable weight 400-700, Latin subset
  literata-latin.woff2  Literata, variable weight 400-700, Latin subset

How they were made (2026-09-20). Start from the Latin-subset variable woff2
files that Google Fonts publishes for these two families, then, in a throwaway
virtual environment with fonttools and brotli installed:

  python -m fontTools.subset FILE.woff2 --flavor=woff2 --no-hinting \
      --unicodes="U+0020-007E,U+00A0-00FF,U+0131,U+0152-0153,U+2013-2014,U+2018-201A,U+201C-201E,U+2022,U+2026,U+2032-2033,U+20AC,U+2122,U+2190-2193,U+2212,U+2215" \
      --layout-features="kern,liga,calt,ccmp,locl,mark,mkmk,tnum,case,ss01" --output-file=FILE-sub.woff2
  python -m fontTools.varLib.instancer FILE-sub.woff2 wght=400:700 -o FILE-final.woff2

Neither copyright notice below declares a Reserved Font Name, and the
subsetting only removes glyphs and part of the weight range. Sources:
https://github.com/rsms/inter and https://github.com/googlefonts/literata
