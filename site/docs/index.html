NovelForge documentation

Updated 20 September 2026

Learn how to install NovelForge, find your way around its window and keep your novel safe. These pages describe NovelForge 2.2.0, one task at a time.

NovelForge is a free novel-writing studio for Windows. Every scene, character sheet and map it makes is an ordinary Word (.docx) file in a folder on your own disk, so these pages talk about files and folders as often as about buttons. If you have not installed it yet, start with Install and first launch; if you already write in it, Keyboard shortcuts is the page most people keep open.

Press / on any page to search the site. Without JavaScript the list below is the whole index: every page, by topic and then A to Z.

Each page says when it was last changed. If something here does not match what you see in the program, that is a bug in these pages, and an issue on GitHub is the quickest way to get it fixed. Every page also has an Edit this page on GitHub link at the bottom.

The pages do not cover everything yet. The features page gives the whole tour in one place, and the FAQ answers the questions people ask before they install.
